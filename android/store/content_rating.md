# 콘텐츠 등급(IARC) 설문 답 초안

플레이 콘솔 '앱 콘텐츠 > 콘텐츠 등급'. 분류는 **기타(참고·생산성·유틸리티 등 게임이 아닌 앱)**를 고릅니다.

| 질문(요지) | 답 | 이유 |
|---|---|---|
| 폭력·피·공포 내용 | 아니요 | PDF 보기·편집 도구. 앱이 스스로 담은 내용 없음 |
| 성적 내용·노출 | 아니요 | 같음 |
| 욕설·저속한 표현 | 아니요 | 같음 |
| 약물·술·담배 | 아니요 | 같음 |
| 도박(실제 돈·모의) | 아니요 | 같음 |
| 사용자끼리 소통·대화(채팅 등) | 아니요 | 다른 사용자와 연결하는 기능 없음 |
| 사용자가 만든 내용을 다른 사용자와 공유하는 기능 | 아니요 | 앱 안 공유 공간 없음. 안드로이드 공유 창으로 사용자가 고른 앱에 파일을 넘기는 것뿐 |
| 위치 공유 | 아니요 | 위치 권한 없음 |
| 디지털 상품 구매 | 아니요 | 인앱 결제 없음 |
| 무제한 인터넷 접근(웹 브라우저 기능) | 아니요 | 인터넷 권한 없음. 링크는 기기 브라우저로 넘김 |

예상 결과: 모든 지역 '전체 이용가(3+ / Everyone)'.

참고: 사용자가 여는 PDF 안의 내용은 앱이 정하지 않으므로 설문 대상이 아닙니다.
