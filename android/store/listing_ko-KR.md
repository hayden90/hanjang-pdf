# 구글 플레이 등록 글(ko-KR) 초안

올리지 않은 초안입니다. 플레이 콘솔 입력은 대표님이 하십니다. 글자 수는 플레이 한도(이름 30, 짧은 설명 80, 자세한 설명 4000) 안입니다.

## 앱 이름
한장PDF

## 짧은 설명
PDF를 보고 형광펜·메모·글자 상자로 표시하고 쪽을 정리해 저장·공유하는 앱

## 자세한 설명
한장PDF는 휴대폰·태블릿에서 PDF 서류를 보고, 표시하고, 쪽을 정리하는 앱입니다.

■ 보기
- 세로로 넘기며 보기, 두 손가락 확대, 폭 맞춤
- 글자 찾기(다음·이전, 찾은 곳 칠해 보이기)
- 글자 끌어 고르기·복사

■ 표시
- 형광펜(노랑·초록·분홍), 메모, 글자 상자(크기·정렬·색), 네모 상자(선·채우기 색·굵기·진하기)
- 지우개, 되돌리기·다시 하기
- PC판 한장PDF와 같은 방식으로 저장해, 한쪽에서 넣은 표시를 다른 쪽에서 고치고 지울 수 있습니다

■ 쪽 정리
- 쪽 목록에서 길게 눌러 끌어 순서 바꾸기
- 고른 쪽 돌리기·지우기·내보내기, 다른 PDF 끼워 넣기

■ 저장·공유
- 기본은 '다른 이름으로 저장'(원본은 그대로). 원본에 덮어쓰기는 고를 때만 하며, 실패하면 원본을 되돌립니다
- '공유'를 누르면 고른 앱으로 사본을 보냅니다

■ 개인정보
- 인터넷 권한이 없어 문서를 스스로 밖으로 보내지 않습니다
- 저장소 권한 없이, 직접 고른 파일만 엽니다
- 광고·분석·회원 가입이 없습니다

한국어·영어 화면(기기 언어를 따름)과 TalkBack·키보드 조작을 지원합니다.
한장PDF는 자유 소프트웨어(GNU AGPL v3)입니다. PDF 엔진은 MuPDF를 씁니다.
소스: https://github.com/hayden90/hanjang-pdf
