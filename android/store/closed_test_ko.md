# 비공개 테스트 안내 초안(테스터 12명 · 14일)

새 개인 개발자 계정은 정식 출시 전에 **비공개 테스트에 테스터 12명 이상이 14일 동안 계속 참여**해야 합니다(플레이 정책, 대표님이 콘솔에서 확인).

## 대표님이 하실 일 순서
1. 플레이 콘솔(부빅터 개발자 계정) > 앱 만들기: 이름 '한장PDF', 기본 언어 한국어, 앱, 무료.
2. 앱 무결성 > **Play 앱 서명** 사용(기본값). 업로드 키는 저장소 밖에 둔 업로드 키(만드는 법은 android/README.md).
3. 앱 콘텐츠: 개인정보처리방침 주소, 광고 없음, 데이터 보안(`data_safety.md`), 콘텐츠 등급(`content_rating.md`), 대상 연령(만 18세 이상 일반 사용자로 고르는 것을 권장. 아동 대상 아님), 정부 앱 아님, 금융 기능 없음, 건강 앱 아님.
4. 테스트 > 비공개 테스트 > 트랙 만들기 → 테스터 목록(구글 계정 이메일 12명 이상) → 새 버전에 `app-release.aab` 올리기 → 출시 노트(아래) → 검토 보내기.
5. 검토 통과 뒤 '참여 링크'를 테스터에게 보냄. 14일 동안 12명 이상이 참여 상태를 유지해야 함.
6. 14일 뒤 '프로덕션 사용 신청' 설문(테스트에서 얻은 것·고친 것)을 내고 승인되면 정식 출시.

## 테스터에게 보낼 안내(문자·메일)
안녕하세요. 휴대폰용 PDF 앱 '한장PDF' 시험판 참여를 부탁드립니다.

1. 아래 링크를 안드로이드 휴대폰에서 열고 '테스터 되기'를 눌러 주세요. (링크)
2. 이어서 나오는 플레이 스토어 주소에서 앱을 설치해 주세요.
3. **14일 동안 앱을 지우지 말고** 가끔 PDF를 열어 봐 주세요(14일 참여가 있어야 정식 출시가 됩니다).
4. 불편한 점은 이 번호로 편하게 알려 주세요.

앱은 인터넷 권한이 없어 문서를 밖으로 보내지 않습니다.
